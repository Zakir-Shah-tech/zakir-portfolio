## ✨ Features

- **⚡ Fast & Lightweight**: Pure HTML, CSS, and Vanilla JavaScript with no heavy frameworks or external dependencies.
- **📱 Fully Responsive**: Seamless experience across mobile screens, tablets, and desktop displays.
- **🎨 Modern Typography & UI**: Powered by custom Unbounded fonts (`.woff2`) and clean section layouts.
- **🧭 Smooth Navigation**: Accessible mobile menu toggle and smooth anchor link transitions.
- **💼 Project Showcase**: Dedicated showcase section for featured projects, case studies, and creative work.
- **📈 Learning Journey**: Transparent timeline of skills mastered, current pursuits (React, Next.js, CS50x), and certifications.

## 🛠️ Tech Stack

- **Markup**: HTML5 (Semantic & Accessible)
- **Styling**: CSS3 (CSS Variables, Flexbox, CSS Grid)
- **Scripts**: Vanilla JavaScript (ES6+)
- **Typography**: Custom Local Font (`Unbounded` 700 & 900 in WOFF2 format)

## 💻 Local Development

To run and edit this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/zakir-shah-tech/zakir-portfolio.git
   cd zakir-portfolio
   ```

2. **Open the project:**
   - Simply double click `index.html` to open it in your browser, or
   - Use VS Code with the **Live Server** extension (right-click `index.html` → *Open with Live Server*).

---

## 🌐 Deploy to GitHub Pages

1. Go to your repository settings on GitHub (**Settings** tab).
2. Click on **Pages** in the left sidebar.
3. Under **Build and deployment** > **Branch**:
   - Select branch: `main`
   - Select folder: `/ (root)`
4. Click **Save**. Your site will be published live in 1-2 minutes!
